# Verilog Practice Lab

A collection of Verilog practice projects focused on digital logic design, RTL development, functional verification, simulation, and waveform analysis.

This repository documents my hands-on journey in digital hardware design, from beginner-level circuits to more challenging digital systems.

## Projects

| No. | Project | Concepts Practiced | Status |
| 1 | [Digital Dice](projects/digital-dice/) | Sequential logic, LFSR, reset, control signals, testbenches, waveform analysis | Completed |
| 2 | Traffic Light Controller | Combinational and sequential logic, control sequencing | Planned |
| 3 | Vending Machine | State-based control, arithmetic, input handling | Planned |

*More projects will be added as I progress.*

## Tools Used

- **Verilog HDL** — RTL design
- **Icarus Verilog** — compilation and simulation
- **GTKWave** — waveform inspection
- **Vivado** — simulation and waveform analysis
- **Visual Studio Code** — development environment
- **Git and GitHub** — version control and project documentation

## Learning Approach

Each project aims to include, where applicable:

- A clear description of the design requirements
- RTL source code
- A testbench with relevant test cases
- Simulation results and waveform evidence
- Documentation of design decisions and limitations
- Possible improvements and future extensions

The goal is to develop sound digital design fundamentals through implementation, debugging, verification, and continuous improvement.

## Scope and Disclaimer

These are educational and practice projects. Their implementation depth, verification coverage, and limitations will be documented honestly as the repository evolves.

The designs are intended for learning and experimentation, not as claims of production-ready hardware.
